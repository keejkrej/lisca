# LISCA user manual

LISCA analyses time-lapse microscopy of cells grown on micropatterned arrays: one cell per pattern spot, followed over time. This manual explains what each step does, which assays LISCA supports, and exactly how every number in your results is calculated, so you know what you are reporting and can cite it.

**Version.** This manual describes LISCA `[VERSION]`. Always report the version you used; it is shown in the app under `[where the version is shown]`.

## How to cite

When you publish results produced with LISCA, cite LISCA and the method behind the assay you used. Each assay page ends with a *Cite this method* box.
