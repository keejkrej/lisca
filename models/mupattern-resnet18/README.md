**Ownership:** this lisca monorepo, **legacy reference only**. Do not train or
ship new killing weights from this directory.

[`lisca-killing-assay`](https://github.com/keejkrej/lisca-killing-assay)
(`killing.inference.register`: frozen EmbeddingGemma 2 plus a linear head).
This directory is not that path.

This directory remains for reference. The former local classifier came from
[mupattern](https://github.com/keejkrej/mupattern).
