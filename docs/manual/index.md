# LISCA user manual

LISCA analyses time-lapse microscopy of cells grown on micropatterned arrays: one cell per pattern spot, followed over time. This manual explains what each step does, which assays LISCA supports, and exactly how every number in your results is calculated, so you know what you are reporting and can cite it.

**Version.** Always report the Studio version you used. It is the version of the installer or GitHub Release you installed (the tag looks like `studio-vX.Y.Z`).

## How to cite

When you publish results produced with LISCA, cite LISCA and the method behind the assay you used. Each assay page ends with a _Cite this method_ box.

!!! quote "Cite LISCA"
    A citable reference for LISCA is in preparation; until then cite the method papers below.

    Methods sentence: *"Single-cell time-lapse data were analysed with LISCA (report the Studio version you installed)."*
